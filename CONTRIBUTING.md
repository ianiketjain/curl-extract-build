# Contributing to curl-extract-build

## Getting Started
1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/extract-curl`
3. Install dependencies: `npm install`
4. Create a branch: `git checkout -b feat/your-feature`

## Development
- Source code is in `index.ts`
- Build: `npm run build`
- Tests are in the `test/` folder

## Submitting a PR
- Keep PRs focused on one change
- Add tests for new features
- Make sure existing tests pass
- Describe what your PR does and why
- Please do not update the existing code. but update the conditions in `index.ts`

## Reporting Bugs
Open a GitHub Issue with steps to reproduce.
